# Third-party content attribution

## Fonts

The page is set in three typefaces, embedded from `site/assets/` and served
from this origin only, so no visitor request leaves it for a letterform. All
three are licensed under the SIL Open Font License, Version 1.1; the licence
text, with these copyright lines, is `LICENSES/OFL-1.1.txt`. The copyright
lines below are the ones each font file carries in its own `name` table.

| File | Face | Copyright |
| --- | --- | --- |
| `site/assets/font-0.ttf` | DM Sans Regular (400) | Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts) |
| `site/assets/font-1.ttf` | DM Sans Medium (500) | Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts) |
| `site/assets/font-2.ttf` | DM Sans SemiBold (600) | Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts) |

The files are served exactly as delivered and are not modified here.

## Google Maps

The area map is a Google Maps embed loaded in the visitor's browser from
Google; its terms are Google's. `compliance.json` declares it, and the
privacy question it raises is an open owner decision recorded there.
